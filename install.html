把镜镜喵带进 Codex

九组动作 · 十六方向视线 · v2 透明精灵图

安装镜镜喵

允许浏览器打开 Codex，在安装窗口完成导入，再到设置的 Pets 页面选择她。

需要已安装支持 Pets 的桌面客户端。安装入口通过 GitHub 下载精灵图，不会修改系统配置。
